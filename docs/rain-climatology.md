# ฝนในภูเก็ตจาก ERA5 (ขั้นที่ 5)

ข้อมูลฝนรายชั่วโมง ERA5 ช่องกริดใกล้ตัวเมืองภูเก็ต 2000-01-01 ถึง 2026-10-31 (235,224 ชั่วโมง, 26.8 ปี) สร้างโดย `scripts/rain_effects.py`

**ข้อจำกัด:** ERA5 เป็นค่าเฉลี่ยบนกริด ~25 กม. ความเข้มฝนรายชั่วโมงสูงสุดต่ำกว่าที่สถานีวัดได้ และมีฝนปรอยเล็กน้อยบ่อยกว่าจริง ตารางนี้ใช้ดูแนวโน้มและเลือกสถานการณ์จำลองเท่านั้น
